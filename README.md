Páginas públicas dos apps da CjLabs, publicadas pelo GitHub Pages em
https://cirojosepadua-maker.github.io/cjlabs/ (Settings → Pages → Deploy from a
branch → `main`, pasta raiz).

| App | Pasta | Original (repositório do app) |
|---|---|---|
| 4eroes | `4eroes/` | `C:\jogos\the-magic-village\site` |

Cada pasta tem `privacidade.html` (português), `privacy.html` (inglês) e o
ícone. O texto é escrito no repositório de cada app e copiado para cá: ao
mudar uma política, mudar lá, copiar e enviar este repositório também.
